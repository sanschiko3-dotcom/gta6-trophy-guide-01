# Leonida Ledger / offline field guide

An independent GTA VI trophy guide and saved checklist for PlayStation 5. V2 adds official descriptions in full, grade words, stage and grade totals, roadmap sorting, previous/next guides and an auditable completion table. All 55 guides include at least two named sources; uncertain triggers are explicitly labelled.

Run `node serve.ts`, then open `http://localhost:8080`. Any static server with `app/` as its root works. No build step, external fonts or external assets. The app loads local data only, and works without internet access. Source links open only when followed.

There are 55 trophies: 1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden. Allow roughly 200 hours. The only missable is Positive Mental Attitude: protect Chapter 1's balcony meditation after Down to Earth and retain an early save. Its strict necessity remains unconfirmed. No online trophies are required.

The audit strip records 55/55 official names, the grade distribution, hidden count and one missable. Names, official descriptions, grades, identities, kinds and stages are preserved byte-for-byte from v1, based on the kit's PlayStation list via Exophase and PSNProfiles. The supplied research brief cross-checks OutputLag, Keengamer and GTABase.

Progress saves to localStorage. Export JSON before switching devices; Import JSON restores a backup after validating IDs. `?sample=1` seeds twelve earned trophies and clearly labels them as sample progress; Reset starts your own tracker. Story spoilers are hidden by default until earned. Search, kind, grade and progress filters combine with Roadmap / Grade / Name sorting.

Deep links: `#roadmap`, `#trophy=28`, `#filter=missable`, `#spoilers=on`.
