Leonida Ledger is an independent, offline GTA VI trophy guide and local progress tracker. Original CSS and typography; no official artwork. Includes cited guides, filters, story spoiler protection, JSON backup and a three-stage platinum roadmap.

Run `node serve.ts` and open localhost:8080, or serve app/ with any static server. No build step or external runtime resources. Source links connect only when followed. Try `?sample=1` for 12 sample earned trophies; clear the labelled sample to start your own. Progress belongs to this browser; export it before clearing site data. Import accepts the exported JSON format.

The supplied verified research lists 55 PS5 trophies: 1 platinum, 2 gold, 6 silver, 46 bronze. Approximately 200 hours, one playthrough, one missable: Positive Mental Attitude. Keep a Chapter 1 manual save; there is no mission replay. Unconfirmed methods are explicitly labelled. Story spoiler protection hides both names and descriptions until earned, independently of PlayStation's hidden flag.

Sources: the kit's official list (Exophase / PSNProfiles), the supplied November 19 research brief, [Keengamer](https://www.keengamer.com/articles/guides/gta-6-trophy-guide-platinum-roadmap-all-55-trophies/), [OutputLag](https://outputlag.com/guides/gta-6-trophy-list/), and [GTABase](https://www.gtabase.com/articles/gta-6/gta-6-achievements-trophies-list-ps5-xbox-series). Each guide cites its supporting source. Guides are original paraphrases; official names, descriptions and grades remain unchanged.

`MAKEFUN_OUTPUT_DIR=/tmp/gta6-out node main.ts` copies the app and real browser captures and produces the dossier using the unchanged kit library. Nothing is submitted by this command.
